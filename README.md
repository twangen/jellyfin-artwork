# Jellyfin Artwork

A collection of custom artwork made for Jellyfin libraries and media sections.

The current **Library Tile Cards** set uses a matching dark blue, black, and gold cinematic theme with large, centered titles designed to stay readable in Jellyfin's landscape card layout.

## Using the Artwork

1. Open the `library_tile_cards` folder.
2. Download the image you want to use.
3. In Jellyfin, open the matching library or section.
4. Select **Edit Images** and upload the file as its primary image.
5. Refresh the page if the new artwork does not appear immediately.
